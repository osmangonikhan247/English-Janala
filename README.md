# English জানালা

An interactive English learning website for Bengali speakers.
Learn vocabulary, pronunciation, and grammar through structured lessons.

## How to Use
1. Open `index.html` in your browser.
2. Enter your name and PIN: `123456`
3. Click **Get Started** to begin learning.

## Features
- Vocabulary lessons by level
- Word pronunciation (text-to-speech)
- Word details with synonyms and examples
- English Quiz

## Files
- `index.html` – Main page
- `play_quiz.html` – Quiz page
- `styles.css` – Custom styles
- `lesson.js` – Fetches and displays vocabulary lessons
- `login.js` – Handles login/logout

## Technologies Used
- HTML, CSS, JavaScript
- Tailwind CSS + DaisyUI
- Font Awesome icons
- Programming Hero Vocabulary API
